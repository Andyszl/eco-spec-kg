## 为什么可以做一次有限试验

真实服务器已经检查1387条配对记录，全部长度≤8192且监督token>0。当前修复训练626条、控制623条，两个内部验证集各69条，沿用原保存的划分，三个长视图继承父单元训练归属。已核实的新增监督包括4条有效训练方法空间关系、被恢复长父单元的34条不同关系，以及保留的2个单位后缀公式绑定输入。

剩余覆盖缺口确实存在：有效train方法空间4/17、约束1/8。候选池增大带来的未匹配金标项仅能称严格规范名称选择任务中的负目标，不能断言其语义皆假。这些限制被明确记录，可做一次seed42有限试验验证组合改动是否有收益；不能承诺严格dev门槛会通过，也不把“审核完成”写成“覆盖全部修好”。这正是先单种子筛选的目的。

## 固定比较协议

| 项目 | 控制臂 | 修复臂 |
|---|---|---|
| train/内部validation | 623/69 | 626/69 |
| seed / data_seed | 42 / 42 | 42 / 42 |
| 更新次数 | 200 | 200 |
| batch / 梯度累积 | 1 / 16 | 1 / 16 |
| LoRA rank/alpha/dropout | 8/16/0.05 | 8/16/0.05 |
| 学习率 / warmup | 0.0002 / 0.1 | 0.0002 / 0.1 |
| 长度 / 精度 | 8192 / BF16 | 8192 / BF16 |
| 验证和保存 | 每40次更新 | 每40次更新 |
| 最佳checkpoint | 内部验证loss最低 | 内部验证loss最低 |

为保持相同更新预算，关闭early_stop_interval，执行满200步；不同臂独立进程、从同一基座重新初始化。使用显式val_dataset、split_dataset_ratio=0，不再次随机划分；训练dataloader仍shuffle，dataset层不再次shuffle。采用Swift4.4.2支持的CLI truncation_strategy=delete及strict=true，模板实际为raise；输入已经逐条检查，若后续出现处理异常应失败，不能默默少训。参数依据：[Swift4.4.2数据参数](https://github.com/modelscope/ms-swift/blob/v4.4.2/swift/arguments/base_args/data_args.py)、[模板参数](https://github.com/modelscope/ms-swift/blob/v4.4.2/swift/arguments/base_args/template_args.py)、[训练参数](https://github.com/modelscope/ms-swift/blob/v4.4.2/swift/trainers/arguments.py)。

该对照识别候选覆盖与长单元恢复的组合效果，不声称单组件因果收益。完整dev评估时，基座与两个LoRA必须共同使用v2.9候选、v2.6提示及同一冻结结构模块，分别报告组合前后结果；本训练命令不调用dev选择checkpoint。

预先确定的dev筛选门槛：3条目标指标绑定全恢复；完整dev实体F1、关系micro/macro均不下降；误选不增加；至少一条含方法/来源的扩展路径完整。只有全部通过才扩三种子。最终新来源独立验证仍需另行完成。

## 入口及失败行为

tools/train_reviewed_pair_20261014.py验证监督审核SHA、已通过服务器预检SHA、6份输入SHA、核心源码/冻结文件SHA、1387条记录的ID与监督长度、tokenizer配置及Swift4.4.2版本。实际安装环境还将检查参数字段存在、四份显式数据经Swift加载条数不变、GPU0空闲与BF16计算，再启动控制/修复两个进程。

任一臂失败立即停止后续臂；完成时要求实际trainer_state为200步、选中的adapter存在且非空、内部验证loss有限。原输出不覆盖，不恢复历史checkpoint，不自动扩种子。工具默认不带--run只验证和展示命令；交付Shell明确带--run。

tools/run_reviewed_pair_20261014.sh依次执行两臂，将pair_manifest和两个训练日志上传独立Git结果分支。只上传记录，不上传模型权重。若训练中失败且有manifest也会回传该失败记录。若启动前检查不通过，会明确打印LAUNCH_BLOCKED_BEFORE_TRAINING并保留错误。

本地测试覆盖输入/审核篡改、完整旧预检匹配、固定预算/显式验证/无resume、安装参数与数据条数模拟、失败停止、未满200步拒绝、空权重拒绝及成功配对记录。测试使用模拟训练器与权重夹具，不能记为真实GPU训练通过。服务器训练尚未执行。
