## 已实施和验证

- `method_supervision_scope_v2.canonicalize_methods`是独立的无选择规范化步骤，供后续训练、基座推理及LoRA推理共用。只合并当前原文支持的既有方法全名/唯一括号缩写及其“基于”触发前缀；不硬编码规范编号、变量、方法名或开发单元。工作流程描述、叙述句边界、歧义缩写保持分开。原候选不修改，合并保留原证据并返回实体/关系ID映射。
- `training_selection_view`只从训练问题的候选关系中去掉已明确登记为未知的边；不会将它们当作未选负例。模型推理使用完整规范化图，不应用训练审核名单，也不自动选边。若未知项与正例冲突、ID不存在，立即报错。
- 当前训练原文审核34条既有方法/来源候选，含15条待裁决项；新增方法候选中K_r有直接定义支持，K′仍待裁决。16条原始待裁决候选去重后为10条关系，隔离对两臂相同。审核名单是训练标签元数据，不是推理硬编码规则。
- 625训练+70验证在内存逐项回放：合并5个方法实体名称变体及9条重复关系，原正例通过ID映射保留，0新增未知推理排除。两臂提示完全相同；验证不应用未知隔离。方法/来源训练正例在投影预览中为控制3条、修复8条，含新审核K_r边；两臂5个训练目标不同。这些数值是监督预览，不能表述为模型召回率。
- `source_review.json`原样保留上一阶段训练原文审核包，包含历史“尚未实施”状态；本阶段实施和回放结果以`verified_report.json`为准。所有审核仍为助手原文审核，不是新增独立人工金标。
