# 求和符号与索引角色修复

候选版本从structure-aware-rule-v2.4升级为v2.5。修复代码在原始V2.2训练包和已在服务器核验的独立训练候选包上分别比较，不修改来源、标注或历史结果。

## 问题、范围与实现

1. A.5规范化表达式为`R = sum(R_半月k, k, 1, 24)`。原识别器把参数分隔逗号并入下标，导致R_半月k漏选。下标现在要求分隔符两侧都有组成部分；完整中文、多层和多维下标继续保留。
2. 明确支持本次来源修订约定的四参数`sum(被求和项, 索引, 下限, 上限)`，处理嵌套括号及已声明下标内部的逗号。索引只在该求和项内绑定；边界、式外同名变量和其他求和式内的自由出现不被删除。x_i等索引量作为完整符号保留。
3. 公式输出只从最外层赋值识别，避免把嵌套的i=1或比较符号误当作另一输出。没有根据当前预测修改审核标注。
4. 此次仅控制公式输入/输出边。独立实体、已有单位/数据来源规则不扩展修改；例如旧标注和候选中的`i/j sourced_from 降雨量资料`仍待单独语义审核。

不支持任意LaTeX/OCR求和布局的自动恢复；三参数sum等其他写法不会被当成已确认的四参数索引绑定。结构不明确时保留词法识别，不臆测绑定范围。A.18、A.23、A.14–A.16三个暂缓审核单元仍保持原状。
