## 2. 在窗口 A 启动 seed43 服务

在原 seed42 服务窗口按 Ctrl+C 结束自己启动的前台服务，等到提示符返回。
下一段默认 `SEED=43`。之后评测 seed44 时，先结束 seed43 服务，再把本段改为 `SEED=44`。
训练随机种子由 adapter 区分；三组推理随机种子均固定为 42。

```bash
conda activate ecospec-train
(
  set -euo pipefail
  SEED=43
  BASE=/home/hello/szl/eco-spec-runs/lora/human_confirmed_20261002_v27
  case "$SEED" in
    43) VERSION=v0-20261004-124937 ;;
    44) VERSION=v0-20261004-132020 ;;
    *) echo "此步骤只用于 seed43 或 seed44"; exit 1 ;;
  esac

  LOG="$BASE/seed${SEED}_deploy_$(date +%Y%m%d_%H%M%S).log"
  test -s "$ADAPTER/adapter_model.safetensors"
  test -f "$ADAPTER/adapter_config.json"
  python - <<'PY'
import socket
with socket.socket() as probe:
    probe.bind(("127.0.0.1", 8017))
PY
  CUDA_VISIBLE_DEVICES=0 swift deploy \
    --model /home/hello/szl/models/Qwen3.5-9B \
    --adapters "eco-lora-seed${SEED}=$ADAPTER" \
    --infer_backend transformers \
    --served_model_name eco-base \
    --torch_dtype bfloat16 \
    --enable_thinking false \
    --temperature 0 \
    --max_new_tokens 3072 \
    --max_length 8192 \
    --seed 42 \
    --host 127.0.0.1 --port 8017 \
    --api_key local-token \
```

等待服务显示监听地址。端口检查失败时，先核查原服务是否已结束，不关闭其他不相关进程。

## 3. 在窗口 B 评测相应 adapter

两窗口的变量不共享。下面的 `SEED=43` 必须与窗口 A 相同；评测 seed44 时，两个窗口都改成 44。
本段调用固定 v2.7 候选、相同提示词和温度，推理 seed42。输出使用新时间戳，已有结果保留。

```bash
conda activate ecospec-train
(
  set -euo pipefail
  SEED=43
  WORK=/home/hello/szl/eco-spec-kg-lora-dev-f61cd53
  DATA="$WORK/deliveries/human_confirmed_20261002"
  RUN="/home/hello/szl/eco-spec-results/lora_v27_dev_20261005/seed${SEED}_$(date +%Y%m%d_%H%M%S)"
  MODEL_NAME="eco-lora-seed${SEED}"
  cd "$WORK"
  test "$(git rev-parse HEAD)" = f61cd5302555ed838e51e4a04587f5279a97c513
  test -z "$(git status --porcelain --untracked-files=no)"
  test ! -e "$RUN"
  export PYTHONPATH="$WORK/src"
  export PYTHONDONTWRITEBYTECODE=1
  export PYTHONIOENCODING=utf-8
  export ECOSPEC_LLM_BASE_URL=http://127.0.0.1:8017/v1
  export ECOSPEC_LLM_API_KEY=local-token
  export ECOSPEC_LLM_ENABLE_THINKING=false
  export NO_PROXY=127.0.0.1,localhost
  export no_proxy="$NO_PROXY"
  unset ECOSPEC_LLM_APPEND_NO_THINK

  python - "$MODEL_NAME" "$DATA/blind/dev_units.jsonl" <<'PY'
import json, sys, urllib.request
from pathlib import Path
request = urllib.request.Request("http://127.0.0.1:8017/v1/models",
    headers={"Authorization": "Bearer local-token"})
with urllib.request.urlopen(request, timeout=10) as response:
    ids = [item["id"] for item in json.load(response)["data"]]
assert sys.argv[1] in ids, f"目标 adapter 未列出：{ids}"
units = [json.loads(line) for line in Path(sys.argv[2]).read_text(encoding="utf-8").splitlines() if line.strip()]
assert len(units) == 22
print("目标 adapter 和开发集数量检查通过：", sys.argv[1])

  echo "本次输出目录：$RUN"
  python -m ecospec_kg.cli_v2 extract-v2 \
    --units "$DATA/blind/dev_units.jsonl" \
    --config config/experiments_v2/qwen35_9b_lora.json \
    --model "$MODEL_NAME" --seed 42 --out "$RUN"

    --units "$DATA/blind/dev_units.jsonl" \
    --predictions "$RUN/predictions.jsonl" \
    --schema "$DATA/schema_v2.json" --out "$RUN/validation"

    --predictions "$RUN/validation/validated_predictions.jsonl" \
    --units "$DATA/blind/dev_units.jsonl" \
    --validation-report "$RUN/validation/validation_report.json" \
    --out "$RUN/evaluation"
  echo "评测完成：$RUN/evaluation/metrics.json"
)
```

每组验收：抽取 `success_count=22/error_count=0`，预测校验 `passed=true`，
evaluate 输出 `gold_nature=human_expert_gold` 及三个 F1，并保存实际结果路径。
失败时本段停止，不用空预测继续计算指标。
