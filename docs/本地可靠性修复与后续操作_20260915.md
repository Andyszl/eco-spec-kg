## 已完成的修复

| 问题 | 新行为 | 边界 |
|---|---|---|
| 字符子串与大小写混淆 | 保留大小写、下标、撇号；函数名不拆为变量；多字符变量优先 | 不负责从损坏PDF文本恢复数学版面 |
| 公式局部符号差异 | 支持每个formula的symbol_aliases，校验目标、引用和说明 | 不内置c/C自动映射，不改旧冻结数据 |

| 当前代码重建历史候选 | 与预测candidate_hash核对；不一致停止 | 不允许通过改写历史哈希绕过检查 |
| 历史候选哈希缺失 | candidate_present为null，selection_result标记candidate_unverified | 误选仍可标记selected_false_positive，但覆盖不作断言 |
| 推理seed和温度仅为标签 | extract-v2传给实际HTTP请求 | 服务是否遵循seed需服务器验证，不替代训练seed |
| 未实现的消融开关静默接受 | use_layout/use_schema/use_evidence仅允许布尔true；其他值提前拒绝 | 未实现全流程去结构/去Schema/去证据实验 |

候选版本为`structure-aware-rule-v2.3`，与提示策略版本是两个独立字段。旧resolved_config中的candidate_generator若不匹配新实现，会报错；应使用新实验配置并保留迁移记录，不修改旧配置冒充历史重现。新运行清单额外记录formula_symbols.py和providers.py的源码哈希。

## 公式局部别名格式

以下仅为经来源审核后可写入新版本数据的格式示例，不是对现有B.2金标的自动裁决：

```json
{
  "formula_number": "B.2",
  "symbol_aliases": [
    {
      "symbol": "c",
      "canonical_symbol": "C",
      "evidence_span_ids": ["填写当前单元已有的真实span_id"],
      "reason": "记录原式和变量说明的局部对应及审核依据"
    }
  ]
}
```

该字段放在单个formula对象上。目标必须在当前变量定义中，原符号不能与另一已定义变量冲突；不能把样例中的占位span直接传入程序。别名只在当前公式生效，不跨公式或标准传播。
